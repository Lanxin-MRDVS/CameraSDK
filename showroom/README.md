# Camera 3D showroom assets

Static Lumio 3D Gaussian Splatting viewer exports embedded by the MRDVS knowledge community. The existing CameraSDK GitHub Pages workflow publishes this directory without changing the SDK documentation.

Current immutable asset set: `cameras/20261126-v2/`.

Model mapping: `mid-black` = S10; `s10-pro` = S10 Pro; `small-black` = S11; `eagal-s2` = M4 Mega; `v2pro` = V2Pro.

Keep each exported viewer, configuration, model data, screenshots, and third-party license notices together. Verify all five viewers before changing knowledge-community URLs. New exports should use a new version directory. Do not replace old version directories while a published page still references them.

These are website assets committed to the repository, not a software Release. Models load only after the visitor clicks the viewer's start button. Source file hashes are recorded in the asset-set manifest.
